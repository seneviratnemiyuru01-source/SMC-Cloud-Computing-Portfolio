M03L1 – Amazon Comprehend PII Detection and Redaction

Overview
This lab demonstrates how Amazon Comprehend detects personally identifiable information (PII) and redacts sensitive information.

Tasks Completed
* Analyzed support tickets utilizing Amazon Comprehend.
* Examined PII detections, offsets and confidence scores.
* Selected a confidence cutoff.
* Uploaded ticket data to Amazon S3.
* Created an Offsets analysis job.
* Created a Redactions analysis job.
* Reviewed 12 lines of redacted output.

AWS Services
* Amazon Comprehend
* Amazon S3
